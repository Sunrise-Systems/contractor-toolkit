# Brand Compliance Checklist

Pre-publish QA for any {{COMPANY_NAME}} branded output. Run this before shipping. The shorter the document, the faster the checklist — but every box still gets checked.

---

## 1. Voice & Copy

- [ ] **Archetype check** — Does this sound like {{VOICE_ARCHETYPE}}? Would a real person say this?
- [ ] **Jargon check** — Is every term understandable to a non-construction reader (unless the audience is professional)?
- [ ] **Specificity check** — Every claim backed by a number, name, date, or concrete example?
- [ ] **Audience check** — Is the audience Pragmatist, Dreamer, or Professional? Is the tone calibrated?
- [ ] **Substitution test** — Could a competitor's name be swapped in without changing the meaning? If yes, it's not specific enough.
- [ ] **CTA check** — Is the next step clear and concrete (not "Contact us today")?
- [ ] **Trust check** — Does this build trust or sound like every other contractor?
- [ ] **Candor check** — Honest about costs, timelines, and trade-offs?
- [ ] **Tagline check** — If "{{TAGLINE}}" appears, does it feel natural and earned? Formatted exactly as written?
- [ ] **Spelling check** — "{{COMPANY_NAME}}" spelled correctly throughout. Sub-brand names spelled correctly.

### Banned word scan

No instances of:
- [ ] synergy / synergistic
- [ ] leverage / utilize (should be "use")
- [ ] holistic
- [ ] cutting-edge / state-of-the-art
- [ ] best-in-class / world-class
- [ ] innovative / innovate
- [ ] game-changing
- [ ] disruptive / disruption
- [ ] scalable (without context)
- [ ] end-to-end (without specifics)
- [ ] solutions
- [ ] stakeholders
- [ ] going forward / at this time / at the end of the day
- [ ] trusted partner (self-applied)
- [ ] turn-key (without explanation)
- [ ] excited to announce

### Style mechanics

- [ ] No passive voice
- [ ] No emojis (unless explicitly requested for social)
- [ ] No exclamation marks in body copy
- [ ] No urgency language
- [ ] No unsubstantiated superlatives
- [ ] Contractions used naturally
- [ ] One idea per sentence

---

## 2. Visual

### Color
- [ ] Colors from the official palette only
- [ ] No off-palette hex codes
- [ ] Body text uses Ink ({{INK_COLOR}}), not pure black
- [ ] Accent color used sparingly — 5 or fewer placements per page
- [ ] No gradients
- [ ] No drop shadows
- [ ] No decorative fills

### Typography
- [ ] {{TYPOGRAPHY_PRIMARY}} specified (or documented fallback)
- [ ] DOCX uses Arial fallback
- [ ] Font weights correct (Regular for headlines unless wordmark/grand-total/division header)
- [ ] ALL CAPS used only for micro-labels, section labels, wordmark, meta labels — never running sentences
- [ ] Letter-spacing applied per spec (negative on tight headlines, positive on uppercase micro-labels)
- [ ] Tabular numerics on currency columns

### Logo
- [ ] Logo file is a real bundled file from `skills/brand/assets/logos/` — no inline-generated logos, no recolored variants
- [ ] Logo color matches the decision tree (sub-brand specific OR primary default OR white-on-dark)
- [ ] Logo variant appropriate for the background (white on dark, black/accent on light)
- [ ] Proper clear space around logo
- [ ] Logo not stretched, rotated, recolored, or effected
- [ ] Logo on cover page only (body pages get no logo; footer uses text wordmark)
- [ ] If sub-brand applies, sub-brand logo used; otherwise parent
- [ ] If ambiguous, the user was asked before rendering

### Layout
- [ ] Left-aligned by default; center only for hero or single-line CTAs
- [ ] Generous whitespace between sections (36-56px min)
- [ ] Max content width respected (900px full / 720px body)
- [ ] Hairline dividers only (0.5px {{RULE_COLOR}}); 1.5px {{INK_COLOR}} above subtotals and grand totals
- [ ] No decorative borders

---

## 3. Structural

- [ ] Right archetype picked for the deliverable (ROM=1, Bid=2, Letter=3, Report=4)
- [ ] Right format for archetype (HTML for visual, DOCX for editable)
- [ ] "Investment" used instead of "Cost" or "Price" in pricing sections
- [ ] CSI division terminology when organizing scope
- [ ] Schedule of Values uses division number + name + total
- [ ] Line items open with direct verbs ("Provide and install…", "Furnish and install…", "Demo and dispose…")
- [ ] Inline exclusions and assumptions per scope item (not buried in appendix)
- [ ] Tabular numerics on currency columns
- [ ] Currency uses thousands separators
- [ ] Ranges use en-dash, not hyphen
- [ ] Validity period explicit on every quoted price
- [ ] Subtotal per division before grand total
- [ ] Grand total has heavier rule than subtotals
- [ ] Footer wordmark + page number on every page of multi-page documents
- [ ] Document reference / revision number in footer of formal documents

---

## 4. Sub-Brand

- [ ] Right brand chosen (parent vs sub-brand) for the content type
- [ ] If sub-brand: sub-brand logo used, not parent
- [ ] Sub-brand voice nuance applied (more design-forward for A&E, more direct for General, more technical for Trade, more numbers-driven for Development)
- [ ] No two sub-brand logos combined on a single page (use parent if content spans divisions)
- [ ] Sub-brand name spelled correctly and consistently

---

## 5. Final Sanity Check

Before clicking "send" or "publish":

- [ ] **Read it out loud.** Does it sound like a person, not a corporate template?
- [ ] **Squint test.** Step back from the document and squint. Is the hierarchy clear? Does the eye land in the right places?
- [ ] **Color test.** Remove all accent color. Is the document still professional and structured? If not, the hierarchy is doing the wrong work.
- [ ] **Competitor swap test.** Replace "{{COMPANY_NAME}}" with a generic competitor's name. Does anything change? If not, the document doesn't differentiate.
- [ ] **Truth test.** Are we telling the truth about cost, schedule, and what we will and won't do? Any sugarcoating eats trust.

If every box is checked — ship it.
