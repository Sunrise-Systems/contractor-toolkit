# Master Clarifications Library

Standard inclusions, clarifications, assumptions, standards of work, and coordination items organized by CSI division and by A&E discipline. **Customize aggressively** based on your standard scope of work.

When generating a proposal, filter to applicable divisions/disciplines from Phase 1. Each item is typed for downstream filtering:

- **Assumption** — what we're presuming about the project
- **Standard of Work** — quality level and code references we'll meet
- **Coordination** — handoff between trades or with owner/architect
- **Allowance** — placeholder amount with rationale (used when scope is incomplete)

## Usage Notes

- **Filter to applicable divisions.** Don't dump the whole library.
- **Distinguish types.** Assumptions go in one section of the proposal, Standards of Work in another, Coordination items in a coordination section.
- **Owner-friendly language.** When the document is going to a client (not a sub), translate technical clarifications to plain English.
- **Sub-friendly language.** When the document is going to a sub, keep the technical language — they need code citations and quality standards.
- **Harvest as you go.** Every project produces new clarifications worth adding to this master file.
