# A&E and GC Fee Reference Data

Professional service fee and contractor markup reference. Based on industry standards and AIA benchmarks. Customize these bands to your market and competitive positioning.

---

## A&E Fee as Percentage of Construction Cost

The most common fee structure for full-service A&E work. Fee percentage generally decreases as construction cost increases (economies of scale in design).

### By Construction Cost Range

| Construction Cost | Fee Range | Typical | Notes |
|-------------------|-----------|---------|-------|
| Under $250K | 12-18% | 15% | Very small projects — high overhead relative to fee |
| $250K - $500K | 10-15% | 12% | Small TI projects |
| $500K - $1M | 8-12% | 10% | Small to mid commercial TI |
| $1M - $2.5M | 7-10% | 8.5% | Mid-range commercial — sweet spot for most regional firms |
| $2.5M - $5M | 6-9% | 7.5% | Larger commercial projects |
| $5M - $10M | 5-8% | 6.5% | Substantial projects |
| $10M - $25M | 5-7% | 6% | Large commercial/institutional |
| $25M - $50M | 4-6% | 5% | Major projects |
| $50M - $100M | 3.5-5.5% | 4.5% | Large-scale development |
| Over $100M | 3-5% | 4% | Mega projects |

### By Project Type (Adjustment to Base Fee)

Some project types require more design effort per dollar of construction cost.

| Project Type | Fee Adjustment | Reason |
|--------------|----------------|--------|
| Standard commercial office | Base (0%) | Baseline |
| Tenant improvement | -5% to -10% | Less site/structural, more interior focus |
| Restaurant / food service | +10% to +20% | Complex MEP, code requirements, finishes |
| Healthcare (non-state-licensed) | +15% to +25% | Regulatory, specialized systems |
| Healthcare (state-licensed) | +30% to +50% | State plan review, extensive documentation |
| Industrial / warehouse | -10% to -15% | Simpler design, less finish work |
| Retail (basic) | -5% to -10% | Relatively straightforward |
| Retail (high-end/flagship) | +10% to +20% | Custom design, detailed finishes |
| Religious / assembly | +5% to +15% | Acoustics, large spans, aesthetics |
| Education | +5% to +15% | State requirements, plan review |
| Multi-family residential | +5% to +10% | Repetitive but complex code |
| Seismic retrofit | +20% to +30% | Analysis-intensive, existing conditions |
| Historic renovation | +25% to +40% | SHPO compliance, preservation standards |
| Mixed-use | +10% to +20% | Multiple occupancy types, complexity |

## A&E Fee Breakdown by Design Phase

How the total fee distributes across project phases. Useful for phased billing and for pricing partial-service contracts.

### Full Service (All Phases)

| Phase | % of Total Fee | Deliverables |
|-------|----------------|--------------|
| Programming/Conceptual | 5-10% | Space program, concept diagrams, preliminary budget |
| Schematic Design (SD) | 15-20% | Floor plans, building sections, elevations, outline specs |
| Design Development (DD) | 20-25% | Detailed plans, system selections, material selections |
| Construction Documents (CD) | 30-40% | Permit set, construction set, full specifications |
| Bidding/Negotiation | 2-5% | Bid packages, addenda, contractor evaluation |
| Construction Administration (CA) | 10-20% | RFIs, submittals, site visits, punch list |

### Partial Service Pricing

When you provide only certain phases:

| Partial Service | % of Full Fee | Notes |
|-----------------|---------------|-------|
| SD through CD (no CA) | 75-85% | Client manages own construction |
| DD through CD (no SD) | 60-70% | Another firm did SD |
| CD only | 35-45% | Another firm did SD + DD |
| CA only | 12-20% | Field support for another firm's documents |
| Permit set only | 40-55% | Minimum viable documents for permit |

## GC Markup Bands

Standard markups carried in GC estimates.

| Markup | Typical Range | Notes |
|--------|---------------|-------|
| **General Conditions** | 8-15% of direct costs | Broken out into superintendent, insurance, site office, temp utilities, dumpsters, safety, cleaning. Duration-dependent. |
| **Overhead** | 8-15% | Home office allocation. Larger GCs trend lower; smaller GCs trend higher. |
| **Profit** | 8-15% | Risk-adjusted return. Negotiable on competitive bids. |
| **Contingency** | 2-35% | Varies by design phase (see below). |
| **Escalation** | 3-6% annualized | Only when construction start is future. |
| **Bond Premium** | 1-3% of contract | If required by owner; typically public work. |

### Contingency by Design Phase

| Design Phase | Contingency Range | Rationale |
|--------------|-------------------|-----------|
| Concept/Programming | 25-35% | High uncertainty, minimal definition |
| Schematic Design (SD) | 15-20% | General layout defined, systems conceptual |
| Design Development (DD) | 10-15% | Major systems defined, details emerging |
| Construction Documents (CD) | 5-10% | Most decisions made, details largely resolved |
| GMP / Bid | 2-5% | Based on actual subcontractor pricing |

## Competitive Positioning

When you have multiple disciplines in-house (architect + engineers + construction), price slightly below market median because:

1. **No subconsultant markup** — engineers in-house don't carry the 10-15% sub markup
2. **Efficiency** — colocated team reduces coordination time
3. **Constructibility** — design-build integration means fewer change orders
4. **Permitting expertise** — code knowledge means fewer plan check corrections

When presenting fees to clients, emphasize **total project cost** (design + construction), not just A&E fee in isolation. Integrated design-build typically saves 5-15% on total project cost versus separate A&E and GC contracts.
